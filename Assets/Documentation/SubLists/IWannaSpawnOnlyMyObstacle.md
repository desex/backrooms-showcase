#### *Я хочу, чтобы спавнился только мой обстакл на плейтесте*

1. Открой файл [ChunkGenerationSettings.asset](./../../Confg/Settings/ChunkGenerationSettings.asset).

![SettingsAsset](./../HowToUseGenerationPictures/SettingsAsset.png)

2. В настройках дистанс групп отставь одну группу и оставь там только прямой чанк.

![DistanceGroupsList](./../HowToUseGenerationPictures/DistanceGroupsSettings.png)

3. Очисти словарь AvailableObstacles

![ClearAvailableObstacles](./../HowToUseGenerationPictures/ClearAvailableObstacles.png)

4. Добавь свой обстакл в словарь

![AddObstacle](./../HowToUseGenerationPictures/AddObstacle.png)

5. Готово!
